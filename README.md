# Muskan QA Portfolio

A dark, QA-focused personal portfolio built with React + Vite.

## 1. Install

```bash
npm install
```

## 2. Run locally

```bash
npm run dev
```

Open the local URL shown by Vite.

## 3. Update your personal links

Open:

`src/config.js`

Replace:

- `YOUR_EMAIL@example.com`
- `+91 XXXXX XXXXX`
- `YOUR_LINKEDIN_URL`
- `YOUR_GITHUB_URL`
- `YOUR_FIVERR_URL`
- `YOUR_ORANGEHRM_GITHUB_URL`
- `YOUR_ECOMMERCE_GITHUB_URL`
- `resume: "#"`

Your Instagram is already set to:

`https://www.instagram.com/muskan.builds23/`

## 4. Build for deployment

```bash
npm run build
```

The production files will be generated in `dist/`.

## Notes

- No fake professional experience or certifications are included.
- API testing is presented as currently learning.
- The AI-assisted test-case generator is clearly marked as an upcoming October 2026 project.
- Project claims are written to be adaptable to your real evidence; update counts only when you have verified numbers.
